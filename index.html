Automatic

ON when distance ≥ ON threshold, OFF when ≤ OFF threshold, otherwise unchanged. Thresholds are set on the receiver's own setup page and cannot be read or changed here. LORA mode only.

Motor commands use shared topics (Motor/control, Motor/mode). Every receiver on this broker account receives them. Changing the motor mode forces the relay OFF. “Sent” only means the broker accepted the message.

MQTT connection

Browsers need the broker's secure WebSocket endpoint (EMQX Cloud: usually port 8084, path /mqtt), not the 8883 port the ESP32 uses. Create a separate dashboard user in EMQX; the password is typed here each time and not saved.
